# 📘 Leçons — Palier 9 : Mobile Flutter

> ✅ **Les 9 leçons de ce palier sont rédigées.** Elles se font **dans l'ordre**, et tu ne coches une leçon que quand **tous** ses critères « Acquis si… » sont vrais.

**Points d'attention** :
- **Teste sur ton vrai téléphone dès le début** (mode développeur + USB) : plus rapide et plus réaliste qu'un émulateur.
- Les deux endroits où les apps de débutants craquent — et que le référent regardera : les **états d'écran** (chargement / erreur / vide / données, systématiquement) et le **hors-ligne**.
