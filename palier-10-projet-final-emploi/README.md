# Palier 10 — Projet final, portfolio & emploi

> 🎯 **Objectif** : assembler TOUT le parcours en un produit réel avec de vrais utilisateurs, puis convertir ça en emploi ou en missions.
> ⏱️ **Volume indicatif** : 8 à 12 semaines (80–120 h). *Le checkpoint est la mesure, pas le calendrier.*
> 📍 **Prérequis** : [épreuve du palier 9](../palier-09-mobile-flutter/evaluation.md) réussie — **tout** le parcours technique est derrière toi.

## 🎓 Ce que tu sauras faire à la fin

1. Cadrer un produit depuis un problème réel de ton entourage.
2. Dérouler **seul** un cycle de projet complet : conception → cahier des charges → chiffrage → planification → suivi → recette → bilan.
3. Assembler un produit multi-clients (web + mobile + API) en justifiant chaque choix.
4. Opérer ce produit en production : CI/CD, monitoring, sauvegardes testées, incidents.
5. Mesurer ton **coefficient d'estimation réel** et l'annoncer en entretien.
6. Présenter ton travail : portfolio, GitHub soigné, CV d'une page, LinkedIn.
7. Faire une **démo de 5 minutes** rodée, compréhensible par un non-technicien.
8. Réussir un entretien technique junior : algo 6 kyu, révisions ciblées, questions de méthode.
9. Répondre de façon convaincante à « comment utilises-tu l'IA ? ».
10. Activer un réseau et envoyer de vraies candidatures ou propositions de mission.

## Module 1 : 🛠️ Projet 8 — Le produit final

Voir [projet.md](projet.md). Un produit complet résolvant un problème réel de ton entourage : web (React/TS) + mobile (Flutter) + API (stack au choix, **justifié** — c'est ça être architecte) + PostgreSQL, dockerisé, CI/CD, déployé sur VPS avec domaine, monitoré, avec une fonctionnalité IA.

**Cycle de gestion de projet complet, de A à Z** — c'est autant l'exercice que le code :
1. Conception (problème, utilisateurs, solution)
2. Cahier des charges (modèle du palier 4, complet)
3. Chiffrage (méthode du palier 6, avec ta vélocité mesurée)
4. Planification en jalons
5. Suivi hebdo (kanban + point d'avancement)
6. Recette (cahier de tests)
7. **Bilan : estimé vs réel**, ligne par ligne
→ Le référent joue le client du cadrage à la recette.

⚠️ Timeboxe : le produit doit *exister* rapidement, pas être parfait. Must-have livré = projet fini ; le reste, c'est des itérations.

## Module 2 : Portfolio & présence en ligne

- [ ] **Site portfolio** (1 page suffit — statique, GitHub Pages, la boucle est bouclée) : 3 projets max, format « problème → solution → stack (et POURQUOI cette stack) → lien live → code ».
- [ ] **GitHub soigné** : README de profil, 4 repos épinglés couvrant tes 4 langages (JS/TS, Python, PHP, Dart), READMEs avec captures, historique de commits régulier (tu l'as déjà si tu as tenu le parcours).
- [ ] **LinkedIn** à jour + **CV d'une page** orienté projets et résultats, pas technologies en vrac.
- [ ] Argument central à mettre en avant : **polyglotte + DevOps + gestion de projet** — le profil « couteau suisse » que cherchent startups et ESN, et le seul employable sur les stacks *existantes* des entreprises (l'immense majorité des offres).

## Module 3 : Préparation aux entretiens

- [ ] Algo : Codewars **6 kyu**, patterns classiques (two pointers, hash map, fenêtre glissante) — dans le langage demandé par l'entreprise (tu as le luxe de choisir).
- [ ] Révision ciblée par sujet : JS/TS (closures, event loop, promesses), React (état, rendu), SQL (JOINs, index), Django/Laravel (ORM, cycle requête), HTTP/sécurité (OWASP), Docker/CI.
- [ ] **Simulations avec l'IA** : « fais-moi passer un entretien technique junior fullstack, corrige mes réponses » — en boucle, par thème.
- [ ] **Simulations avec le référent** : 2–3 entretiens complets en conditions réelles (technique + RH), débriefés.
- [ ] **Démo de 5 minutes du projet 8**, rodée : le problème, la démo live, un choix technique défendu, une difficulté surmontée.

## Module 4 : La recherche

- [ ] Réseau d'abord : **GDG Yaoundé/Douala**, meetups Python/JS/Flutter, écosystème **Silicon Mountain** — y présenter ton projet 8 si l'occasion existe (lightning talk = crédibilité immédiate).
- [ ] Cibles locales : startups (fintech, agritech, e-commerce), ESN, PME qui digitalisent.
- [ ] Freelance : Upwork/Malt — commencer petit ; les missions **PHP/Laravel et WordPress** y sont les plus accessibles pour débuter (ton palier 6 paie ici).
- [ ] Remote junior : plus dur mais possible avec ton portfolio déployé + GitHub actif.
- [ ] Demander au référent : relecture de CV, contacts de son réseau, avis honnête sur ta préparation.

## 🤖 Fil rouge IA — le multiplicateur (et après)

- Sur le projet 8, tu peux enfin travailler comme un pro outillé : **agents (Claude Code) sur des tâches entières** — mais tu es l'architecte et le reviewer de chaque diff.
- En entretien : sache expliquer TA méthode d'usage de l'IA (le fil rouge de ce parcours est une excellente réponse — elle rassure sur les deux fronts : tu sais coder sans, tu es productif avec).

Le métier s'apprend en le faisant.
