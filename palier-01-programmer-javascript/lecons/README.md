⭐ **Leçon 06** est la plus rentable du palier : `map`/`filter`/`reduce` existent dans les quatre langages du parcours (list comprehensions en Python, `array_map` en PHP, méthodes de `List` en Dart). Les maîtriser ici, c'est les reconnaître partout ensuite.

## Comment travailler ces leçons

- **Tape tout.** Aucun copier-coller, y compris depuis ces leçons. Le code qui passe par tes doigts est le seul qui entre dans ta mémoire.
- **Exécute tout.** Chaque exemple : `node fichier.js`. Modifie-le, casse-le, observe le message d'erreur. C'est l'exercice.
- **Fais les exercices avant de lire les corrections.** Une correction lue avant d'avoir essayé n'apprend rien (voir [prompter-une-ia.md](../../guides/prompter-une-ia.md)).
- **2 katas par semaine** dès maintenant → [../../katas.md](../../katas.md). Ce rituel dure tout le parcours.
