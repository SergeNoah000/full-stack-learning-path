# 🛠️ Projet 3 — Clone simplifié d'une app connue

## 📋 Gestion de projet (enrichie — AVANT de coder)
- [ ] **User stories** priorisées MoSCoW dans `docs/user-stories.md` (« en tant que… je veux… afin de… »).
- [ ] **Maquette Figma** simple (2–4 écrans).
- [ ] **Kanban GitHub Projects** lié aux issues du repo ; tâches découpées à < 2h.

## Brief
Au choix (un seul !) :
- **Gestionnaire de tâches** type Todoist (projets, tâches, échéances, filtres) ;
- **Catalogue de films** type Letterboxd (recherche via l'API TMDB, notes, listes) ;
- **Marketplace simple** (annonces, recherche, filtres — données d'une API factice type json-server).

## Fonctionnalités (must)
- [ ] 3–4 pages avec **React Router** (liste, détail, création/édition, à propos).
- [ ] Données via API avec **TanStack Query** : états loading / error / empty gérés partout.
- [ ] Formulaire contrôlé avec validation et messages d'erreur.
- [ ] Responsive, stylé avec **Tailwind CSS**.

## Contraintes techniques
- **Vite + React + TypeScript strict** — zéro `any`.
- 🏗️ Structure par feature ; logique métier dans des fonctions pures hors composants.
- 🤖 Copilot autorisé sur le boilerplate uniquement — chaque ligne acceptée est comprise.

## 🚀 Déploiement : **Vercel**
- Repo GitHub connecté, déploiement auto à chaque push ; explore les preview deployments sur une branche.

## Définition de « fini »
- [ ] Toutes les user stories « Must » livrées, les autres explicitement reportées ou abandonnées (kanban à jour).
- [ ] En ligne sur Vercel ; revue du référent (découpage des composants, gestion d'état).
