# 🧭 Guides transversaux

> Les procédures et méthodes qui servent **à tous les paliers**. Les guides propres à un palier (installer LAMP, sécuriser un VPS…) sont dans `palier-XX-.../guides/`.
>
> Un guide ≠ une leçon. Une **leçon** enseigne un concept (`lecons/`). Un **guide** se suit, étape par étape, pour accomplir quelque chose.
