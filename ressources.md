# 📚 Ressources — la bibliothèque du parcours

> Toutes les ressources du parcours, regroupées. **Règle d'usage** : la doc officielle d'abord, le cours structuré ensuite, la vidéo en dernier recours (une vidéo se regarde, une doc se pratique).
> **Règle anti-zapping** : une ressource principale par palier. Les autres servent à débloquer un point précis, pas à être suivies en parallèle.

## ⭐ Les 5 incontournables du parcours entier

| Ressource | Quoi | Quand |
|-----------|------|-------|
| **MDN** — developer.mozilla.org | La bible du web (HTML, CSS, JS, HTTP). En anglais. | Paliers 0 à 10, tous les jours |
| **The Odin Project** — theodinproject.com | Cursus gratuit, structuré, orienté projets. Ta colonne vertébrale paliers 0–4. | Paliers 0 à 4 |
| **javascript.info** | Le meilleur livre JS en ligne, gratuit, progressif. | Paliers 1 à 3 |
| **Exercism** — exercism.org | Katas + mentorat humain gratuit, dans tes 4 langages. | Paliers 1 à 10 |
| **roadmap.sh** | Cartes du métier (frontend, backend, devops) pour situer ce que tu apprends. | À consulter en début de palier |

## Par palier

### Palier 0 — Fondations
- **learngitbranching.js.org** — Git en visuel et interactif. À finir en entier, c'est court.
- **cmdchallenge.com** — le terminal sous forme de jeu.
- The Odin Project → *Foundations* (Command Line Basics, Git Basics).
- MDN → *How the web works*, *What is a URL*, *What is a web server*.
- code.org → *How the Internet Works* (vidéos, 5 × 8 min).

### Palier 1 — Programmer avec JavaScript
- **The Odin Project → Foundations (JavaScript)** — ressource principale.
- **javascript.info** → chapitres 1 à 6 — pour approfondir un point précis.
- **« What the heck is the event loop anyway? »** (Philip Roberts, JSConf, 26 min) — la vidéo la plus rentable du parcours.
- Exercism piste JavaScript · Codewars 8 kyu.

### Palier 2 — Frontend web
- The Odin Project → *HTML Foundations* puis *CSS Foundations* + *Intermediate CSS*.
- **css-tricks.com** → *A Complete Guide to Flexbox* et *to Grid* (à garder ouverts).
- **Flexbox Froggy** et **Grid Garden** — jeux, 30 min chacun.
- MDN → *Accessibility basics* · **web.dev/learn/css**.
- Sites à reproduire : dribbble.com, land-book.com (prendre une capture et intégrer).

### Palier 3 — React + TypeScript
- **react.dev** → *Learn React* (la nouvelle doc officielle est excellente, suis-la dans l'ordre).
- **typescriptlang.org** → *TypeScript Handbook* + *TS for JS Programmers*.
- **Total TypeScript** (exercices gratuits de Matt Pocock) · **react-hook-form**, **zod** (docs).
- **Figma** (gratuit) pour les maquettes.

### Palier 4 — Backend Node
- **expressjs.com** (doc) · **nodejs.org/docs** (modules `http`, `fs`, `path`).
- **SQL** : sqlbolt.com (interactif, 1 h) puis *use-the-index-luke.com* (index et performance).
- **Prisma** → doc *Getting Started* · **PostgreSQL tutorial** (postgresqltutorial.com).
- **OWASP Top 10** (owasp.org) — à lire une fois, à relire au palier 10.
- **jwt.io** (comprendre un token) · **Vitest / Jest** (docs) · **Postman** ou **Bruno** (tester des API).

### Palier 5 — Backend Python
- **docs.python.org** → tutoriel officiel · **Exercism** piste Python.
- *Python Crash Course* (livre, Eric Matthes) — si tu veux un support papier.
- **PEP 333** (la spec WSGI, à lire vraiment : c'est 1 fonction) · **Jinja2** doc.
- **flask.palletsprojects.com** → *Quickstart* + le tutoriel officiel complet.
- **fastapi.tiangolo.com** → le tutoriel (le meilleur de l'écosystème Python).
- **docs.djangoproject.com** → *Writing your first Django app* (7 parties) + **DRF** (django-rest-framework.org).
- **Real Python** (realpython.com) — articles de qualité sur des points précis.

### Palier 6 — Backend PHP
- **php.net** — la référence (lis les commentaires utilisateurs, c'est une mine).
- **phptherightway.com** — ce qu'est le PHP moderne, contre les vieux tutoriels.
- **httpd.apache.org/docs** → *mod_rewrite* et *.htaccess* (la doc, pas un générateur en ligne).
- **laravel.com/docs** (excellente) · **Laracasts** (séries gratuites, dont *Laravel from Scratch*).
- **PSR-4** (php-fig.org) pour l'autoloading · **Composer** doc.
- WordPress (optionnel) → developer.wordpress.org → *Theme Handbook*, *Plugin Handbook*.

### Palier 7 — Architecture
- **refactoring.guru** — patterns + refactoring, visuel, gratuit, en français aussi.
- **System Design Primer** (github.com/donnemartin/system-design-primer) — les sections de base.
- **ByteByteGo** (YouTube) — schémas de system design.
- *Clean Architecture* (R. C. Martin) ou *Fundamentals of Software Architecture* — si tu lis un livre, un seul.
- **12factor.net** — court, structurant, directement utile au palier 8.

### Palier 8 — DevOps
- **docs.docker.com** → *Get Started* + *Dockerfile best practices*.
- **docs.github.com/actions** → *Quickstart* + *Workflow syntax*.
- **Nginx** (nginx.org/en/docs) ou **Caddy** (caddyserver.com/docs — HTTPS automatique).
- **DigitalOcean Community Tutorials** — les meilleurs tutoriels Linux/serveur du web (gratuits).
- **Let's Encrypt / certbot** doc · **ufw**, **fail2ban** (doc Ubuntu) · **UptimeRobot** (gratuit).
- **explainshell.com** — colle une commande, elle t'explique chaque flag (⚠️ à utiliser AVANT d'exécuter).

### Palier 9 — Mobile Flutter
- **docs.flutter.dev** → *Get started* + *Cookbook* (recettes courtes, très efficace).
- **dart.dev/guides** → *Language tour* · **pub.dev** pour les packages.
- **Flutter YouTube officiel** → *Widget of the Week* (1 min par widget).
- **riverpod.dev** ou **bloc** (doc) pour la gestion d'état · **sqflite**, **hive** (hors-ligne).

### Palier 10 — Projet final & emploi
- **Codewars 6 kyu** · **LeetCode Easy** (format entretien).
- **roadmap.sh/questions** — questions d'entretien par domaine.
- **GDG Yaoundé / Douala**, meetups locaux, écosystème **Silicon Mountain**.
- **Upwork**, **Malt**, **Fiverr** (freelance) · **LinkedIn**, **remoteok.com** (remote junior).
- **github.com/readme** → soigner son profil · **Shields.io** (badges de README).

## 🚫 Les pièges de ressources

1. **Collectionner les cours** sans en finir un. Un palier = une ressource principale.
2. **Les tutoriels de plus de 3 ans** sur PHP, React ou Node : les pratiques ont changé (regarde la date avant de lire).
3. **Les vidéos de 10 h « Full Course »** : impossible à pratiquer en parallèle. Préfère un cursus écrit.
4. **Les traductions automatiques de doc** : vocabulaire faussé, retard de version. Anglais, toujours.
5. **Payer avant d'avoir fini le gratuit.** Tout le parcours est faisable à 0 € (hors VPS et domaine).
