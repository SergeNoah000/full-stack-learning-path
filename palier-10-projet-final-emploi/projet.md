# 🛠️ Projet 8 — Le produit final

> L'assemblage de tout le parcours : un produit réel, pour de vrais utilisateurs, géré comme un projet professionnel de bout en bout. C'est LA pièce maîtresse de ton portfolio.

## Le choix du sujet (à faire avec soin)
Un problème **réel de ton entourage** — le meilleur portfolio est un produit utilisé. Critères :
- Tu connais personnellement ≥ 5 utilisateurs potentiels.
- Le must-have est livrable rapidement (timeboxé) — méfie-toi des idées « plateforme qui révolutionne… ».
- Il justifie web + mobile (sinon, assume de ne faire que l'un des deux et justifie-le).

## 📋 Gestion de projet — le cycle complet (c'est autant l'exercice que le code)
1. [ ] **Conception** : problème, utilisateurs, solution, maquettes Figma.
2. [ ] **Cahier des charges** complet — validé par le référent-client.
3. [ ] **Chiffrage** avec TA vélocité mesurée (projets 4→7) : c'est ton chiffrage le plus fiable à ce jour.
4. [ ] **Planification** en jalons démontrables.
5. [ ] **Suivi hebdo** : kanban + point d'avancement écrit (3 lignes : fait / prévu / risques).
6. [ ] **Recette** avec cahier de tests, déroulée avec le référent-client.
7. [ ] **Bilan final** : estimé vs réel ligne par ligne + rétrospective (que referais-je autrement ?).

## Exigences techniques (la synthèse du parcours)
- [ ] **Web** : React + TypeScript.
- [ ] **Mobile** : Flutter (partageant la même API).
- [ ] **API** : la stack la plus adaptée au besoin parmi tes trois — **choix justifié par écrit** dans `ARCHITECTURE.md` (c'est ça, être architecte).
- [ ] **PostgreSQL** + migrations propres.
- [ ] **Une fonctionnalité IA** utile (pas gadget), clé côté serveur, coûts estimés dans le budget.
- [ ] **Docker** + **CI/CD GitHub Actions** : push sur `main` → tests → build → déploiement.
- [ ] **Production sur VPS** : HTTPS, nom de domaine, monitoring uptime, **sauvegardes automatisées ET testées**.
- [ ] Tests sur la logique métier et les routes critiques.

## Définition de « fini »
- [ ] En production, avec de **vrais utilisateurs actifs** et une boucle de retours en place.
- [ ] Recette signée par le référent-client ; bilan et rétrospective rédigés.
- [ ] **Démo de 5 minutes rodée** (support du module entretiens).
- [ ] Le repo est exemplaire : c'est lui qu'un recruteur ouvrira en premier.
