# 🛠️ Projet 1 — Gestionnaire de dépenses (CLI)

> Ton étalon inter-langages : tu le réécriras en TypeScript (palier 3), en Python avec ton mini-framework (palier 5) et en Dart (palier 9). Soigne-le.

## Brief
Un outil en ligne de commande (Node.js) pour suivre ses dépenses personnelles.

## Fonctionnalités (must)
- [ ] Ajouter une dépense : montant, catégorie, description, date.
- [ ] Lister les dépenses (toutes / par catégorie / par mois).
- [ ] Supprimer une dépense par son id.
- [ ] Total général et totaux par catégorie.
- [ ] Persistance dans un fichier JSON.

## Nice-to-have (seulement si le must est fini)
- [ ] Budget mensuel par catégorie + alerte de dépassement.
- [ ] Export CSV.

## Contraintes techniques
- Node.js pur (pas de bibliothèque externe sauf éventuellement pour les couleurs).
- Fonctions courtes, nommage clair, pas de variable globale baladeuse.
- Gestion des erreurs : entrée invalide = message clair, pas un crash.

## Livrables
- Repo GitHub dédié, commits réguliers, README (quoi, comment l'installer, comment l'utiliser, capture du terminal).

## Définition de « fini »
- [ ] Les 5 must fonctionnent, démontrés au référent.
- [ ] Le README permet à quelqu'un d'autre de l'utiliser sans ton aide.
