# 🧾 Templates

> Les documents réutilisables du parcours. **Mode d'emploi** : ne modifie jamais le template — copie-le dans le dossier `docs/` du repo du projet concerné, puis remplis la copie.
>
> ```bash
> cp ~/Documents/apprentissage/templates/mini-cadrage.md ~/dev/projet-meteo/docs/cadrage.md
> ```
