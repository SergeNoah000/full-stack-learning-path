# Palier 1 — Apprendre à programmer, avec JavaScript

> 🎯 **Objectif** : savoir PROGRAMMER (résoudre des problèmes), pas juste connaître une syntaxe. **Le palier le plus important du parcours** — c'est lui qui rendra Python, PHP et Dart faciles. Ne le précipite pas.

## Module 1 : Bases du langage

- [ ] Variables (`let`, `const`), types (string, number, boolean, null/undefined), opérateurs.
- [ ] Conditions (`if/else`, `switch`), boucles (`for`, `while`).
- [ ] Fonctions : déclaration, paramètres, valeur de retour.
- [ ] Tableaux et objets : créer, lire, modifier, parcourir.
- 🧩 Dès maintenant : **2 katas de 30 min/semaine** — Exercism (piste JavaScript, avec mentorat gratuit) ou Codewars 8 kyu. Ce rituel dure tout le parcours.
- 📚 *The Odin Project → Foundations (JavaScript)* — ta colonne vertébrale ; **javascript.info** pour approfondir un point précis.

## Module 2 : Approfondissement

- [ ] Fonctions fléchées, portée (scope), closures (l'intuition suffit).
- [ ] **`map`, `filter`, `reduce`, `find`, `sort` — à maîtriser parfaitement.** Ces concepts existent partout : list comprehensions en Python, `array_map` en PHP, méthodes de `List` en Dart. Les maîtriser ici = les reconnaître ensuite.
- [ ] Destructuring, spread/rest, template literals.
- [ ] Erreurs : `try/catch`, lire une stack trace **calmement, de haut en bas** (compétence n°1 du débogage).

## Module 3 : L'asynchrone (le cap difficile — c'est normal de galérer)

- [ ] Callbacks → Promises → `async/await` (dans cet ordre, pour comprendre ce que chaque étape a résolu).
- [ ] `fetch()` : consommer une vraie API publique (PokéAPI, API météo…) en script Node.
- [ ] L'event loop : vidéo *« What the heck is the event loop anyway? »* (Philip Roberts) — l'intuition, pas les détails.

## Module 4 : Structures de données & complexité (initiation)

- [ ] Tableaux vs objets/Maps : quand utiliser quoi.
- [ ] Pile, file : le concept et un exemple d'usage.
- [ ] Intuition de la complexité : pourquoi une boucle dans une boucle devient lente ; chercher dans un tableau vs dans une Map.

## Module 5 : 🛠️ Projet 1 — Gestionnaire de dépenses en CLI

Voir [projet.md](projet.md). Ce projet se réécrira en TypeScript (palier 3), Python (palier 5) et Dart (palier 9) — c'est ton étalon de comparaison entre langages.

## 🤖 Fil rouge IA — niveau 1 : le débogueur socratique

- Bloqué > 30 min → demande **un indice, pas la réponse** : « donne-moi une piste sans écrire le code ».
- Après chaque exercice réussi : « critique ma solution — lisibilité, cas limites oubliés ».
- Toujours **zéro code généré**. Tu tapes tout.

## 🧑‍🏫 Référent

- Point régulier : montrer 2–3 katas et le projet 1 en cours. Lui demander de regarder tes habitudes (nommage, commits) plus que ton code.
- C'est le palier du découragement classique (l'asynchrone !) — le point « juste pour parler » existe pour ça.
